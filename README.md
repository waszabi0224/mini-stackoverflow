Ez a projekt egy nagyon egyszerű helpDesk féle webalkalmazás, az ismert StackoverFlow-hoz hasonló szerkezettel (csak sokkal egyszerűbb).
JavaScript nyelven íródott,
Node.js futtatókörnyezetet használtam (backend + frontend),
Express.js keretrendszert használtam,
PostgerSQL adatbázis,
Tailwind css-t használtam, ahol nincs külön .css fájlok (className).
